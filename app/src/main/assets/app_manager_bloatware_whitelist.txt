# Daftar package aplikasi sistem/bawaan pabrik yang DIKENAL LUAS aman untuk
# di-nonaktifkan (freeze) tanpa mengganggu fungsi inti Android — dipakai
# AppManagerCatalog untuk menyaring app kategori "Bloatware" yang ditampilkan
# di App Manager (lihat KDoc AppManagerCatalog untuk alasan kenapa TIDAK
# menampilkan semua app sistem secara bebas).
#
# Format: satu package name per baris, '#' untuk komentar/baris kosong
# diabaikan — SAMA PERSIS dengan format assets/gamelist.txt.
#
# HANYA app yang benar-benar TERPASANG di perangkat yang akan tampil —
# baris yang tidak cocok apa pun di perangkat pengguna otomatis dilewati
# (lihat AppManagerCatalog.loadBloatwareEntries), jadi daftar ini aman
# dibuat mencakup banyak vendor sekaligus tanpa masalah di perangkat lain.
#
# Referensi pemilihan: daftar ini mengikuti kategori "Aman dihapus/dinonaktifkan"
# pada proyek Universal Android Debloater (UAD) — bukan tebakan sepihak.
# TETAP baca deskripsi tiap app di UI App Manager sebelum freeze; kalau
# ragu, jangan freeze dulu — freeze SELALU reversibel lewat tombol yang sama
# di App Manager, tapi lebih aman memverifikasi dulu daripada menyesal.
